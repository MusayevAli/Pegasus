## Exact external prerequisites

Live in-app extras, seats, quote validation and orders require Pegasus business onboarding, issued test credentials, allowed server IPs, authorised NDC schemas/workflows, implementation mapping and certification. The existing NDC class intentionally reports unsupported; public documentation and anonymous MCP search do not complete those services. Global Connect/Dohop combined offers require authorised partner integration and verified conditions.

Real sandbox Apple Pay requires an Apple Developer team, matching merchant ID/entitlements, payment-processing certificates, a supported device/sandbox account, an authorised PSP implementation and compatible airline quote/order/payment workflow. Authorisation, capture and ticket issuance remain separate. None was configured or executed as a real charge/order during verification.

Each deployment needs its own server-side OpenAI key/model access, HTTPS hosting and production identity/operational controls. Physical-device installation needs signing and reachable backend networking. Full accessibility/device QA and the native packing visual acceptance path are verification work, not missing airline credentials.

Existing check-in, boarding-pass/Wallet, Live Activities, hotel/insurance and BolBol modules were not rebuilt; the brief explicitly excluded rebuilding every baseline service. No production airline release, real ticket or automatic purchasing is claimed.
